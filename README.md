# wolf_controller

ROS controller plugin that integrates WoLF with ros_control and ros2_control.

The [ROS 2 MPC contract](docs/mpc_ros2_contract.md) documents observation layout,
named references, planned contacts and the stale-reference emergency response.

## Setup

For installation and workspace setup, see [wolf-setup](https://github.com/graiola/wolf-setup).
